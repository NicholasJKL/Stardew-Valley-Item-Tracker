# 🌾 Stardew Valley Item Tracker

**Вайб-код веб-приложение** для удобного трекинга и коллекционирования предметов в Stardew Valley. Больше не нужно держать в голове, что вы уже скрафтили, а что еще предстоит найти!

## ✨ Особенности

*   **Разделение по категориям:** Объекты, инструменты, оружие, мебель, одежда и многое другое.
*   **Умный поиск:** Быстрый поиск нужного предмета из категории по названию прямо в интерфейсе.
*   **Золотые руки (Достижение):** Специальная категория, которая объединяет предметы, необходимые для внутриигрового достижения "Золотые руки".
*   **Сохранение прогресса:** Данные надежно хранятся в `localStorage` вашего браузера.
*   **Экспорт и Импорт:** Возможность скачать свой прогресс в JSON-файл и загрузить его обратно (на случай очистки кэша или переноса на другое устройство).
*   **Ссылки на Wiki:** Быстрый переход на страницу предмета в официальной энциклопедии Fandom.
*   **Стильный дизайн:** Приятная глазу «стеклянная» тема с использованием Tailwind CSS.

## 🛠️ Стек технологий

*   **React** + **TypeScript**
*   **Vite** (сборка)
*   **Tailwind CSS** (стилизация)
*   **shadcn/ui** (UI-компоненты)
*   **Lucide React** (иконки)

Все актуальные ID, названия, локализации и иконки предметов были взяты из открытого репозитория [MateusAquino/stardewids](https://github.com/MateusAquino/stardewids). Огромная благодарность автору.

## 📥 Скачать готовую версию

Если вы не хотите возиться с установкой Node.js и сборкой проекта, вы можете скачать **готовый HTML-файл**, который открывается в любом браузере без интернета.

1. Перейдите в раздел [Releases](https://github.com/NicholasJKL/Stardew-Valley-Item-Tracker/releases) (справа на странице репозитория).
2. Скачайте последний файл `index.html`.
3. Просто откройте его двойным кликом в вашем браузере. Всё готово!

## 🚀 Локальный запуск

Если вы хотите запустить проект локально:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/NicholasJKL/Stardew-Valley-Item-Tracker.git
```
2. Установите зависимости:
```bash
npm install
```
3. Запустите сервер разработки:
```bash
npm run dev
```
4. Для сборки production-версии выполните:
```bash
npm run build
```
После сборки готовый проект появится в папке dist. Для локального просмотра собранной версии используйте:
```bash
npm run preview
```
